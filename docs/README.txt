PDF Signer landing page for GitHub Pages

Upload the contents of this folder to the root of the tom591/pdf-signer repository (or to the publishing branch/folder selected in GitHub Pages).

GitHub repository → Settings → Pages → Deploy from a branch → main / (root) → Save.

English: index.html
Czech: index_cs.html

Download buttons point to https://github.com/tom591/pdf-signer/releases (no specific release assumed).
All files are local, with no analytics, fonts, cookies or third-party scripts.
